موقع دبلجة — ملفات الموقع الجاهزة
- افتح index.html لمعاينة الموقع في متصفح يدعم الملفات المحلية.
- الصور في مجلد assets.
- عدّل بريد الفريق داخل index.html عند معرفة عنوانه الصحيح.
- Google Sites لا يستورد مجلد HTML كاملًا مباشرة؛ هذا موقع HTML مستقل جاهز للاستضافة، ويمكن استخدام تصميمه كمرجع لبناء نسخة داخل Google Sites.
